## 三、 选题背景与意义

### 3.1 研究背景

**Web安全威胁现状：**
- SQL注入、XSS、命令注入等攻击猖獗
- CC攻击导致服务不可用
- 数据泄露事件频发

**传统防护的不足：**
- 网络防火墙无法检测应用层攻击
- 中小企业缺乏专业安全团队
- 部署成本高，使用门槛高

### 3.2 研究意义

**理论意义：**
- 研究Web攻击检测算法
- 探索分布式防护架构

**实践意义：**
- 为中小企业提供低成本防护方案
- 提供可视化运营界面

## 七、 系统详细设计

### 7.1 规则引擎设计

```
规则结构：
{
    "name": "SQL注入规则",
    "category": "sql_injection",
    "pattern": "(?i)(UNION.*SELECT)",
    "severity": "high",
    "description": "UNION注入检测"
}

匹配流程：
请求 → 解析 → 遍历规则 → 正则匹配 → 判定
```

### 7.2 CC防护设计

```
滑动窗口算法：
┌────────────────────────────────────────┐
│  时间窗口 (60秒)                        │
│  [t1, t2, t3, ..., tn]                 │
└────────────────────────────────────────┘
         ↓
   计数 > 阈值？
         ↓
    是 → 触发封禁
    否 → 放行
```

### 7.3 GeoIP设计

```
IP归属地查询：
IP地址 → 匹配IP段 → 国家代码 → 策略判断

配置示例：
{
    "rule_type": "blacklist",
    "country_codes": ["US", "UK", "JP"]
}
```

### 7.4 URL级策略设计

```
策略匹配：
请求路径 → 正则匹配URL规则 → 获取策略配置

配置示例：
{
    "path_pattern": "^/admin/.*",
    "rule_categories": ["sql_injection", "xss"],
    "cc_rate": 30,
    "override_site_rule": true
}
```
