## 🔧 使用方法

### 1. CIDR格式支持

支持在黑/白名单中使用CIDR格式的IP段：

**示例：**
- 单IP：`192.168.1.100`
- IP段：`192.168.1.0/24`
- 大网段：`10.0.0.0/8`

**API接口：**
```bash
# 添加CIDR白名单
POST /api/access/whitelist
{
    "ip": "192.168.1.0/24",
    "remark": "办公网段"
}

# 添加CIDR黑名单
POST /api/access/blacklist
{
    "ip": "10.0.0.0/8",
    "reason": "内网IP段",
    "duration": 3600
}
```

---

### 2. 区域访问控制（GeoIP）

根据IP归属地进行访问控制。

**国家代码：**
- `CN` - 中国
- `US` - 美国
- `UK` - 英国
- `JP` - 日本
- `RU` - 俄罗斯
- 等等...

**API接口：**
```bash
# 添加区域黑名单
POST /api/sites/{site_id}/geo-rules
{
    "rule_type": "blacklist",
    "country_codes": ["US", "UK", "JP"]
}

# 添加区域白名单
POST /api/sites/{site_id}/geo-rules
{
    "rule_type": "whitelist",
    "country_codes": ["CN"]
}

# 查询IP归属地
GET /api/geo/country/{ip}
```

**配置优先级：**
1. 白名单：只允许白名单中的国家访问
2. 黑名单：阻止黑名单中的国家访问
3. 白名单优先级高于黑名单

---

### 3. 端口管理

为站点配置允许访问的端口，访问未配置端口将返回422错误。

**API接口：**
```bash
# 添加端口
POST /api/sites/{site_id}/ports
{
    "port": 8080,
    "protocol": "http"
}

# 删除端口
DELETE /api/sites/{site_id}/ports/{port}

# 更新端口状态
PUT /api/sites/{site_id}/ports/{port}/status
{
    "status": "disabled"
}

# 查看站点端口
GET /api/sites/{site_id}/ports
```

**422错误页面：**
当访问未配置的端口时，返回以下信息：
- HTTP 422 状态码
- 显示当前访问的端口
- 显示可用的端口列表

---

### 4. URL级防护策略

针对特定URL路径配置独立的防护规则，支持规则覆盖。

**API接口：**
```bash
# 添加URL规则
POST /api/sites/{site_id}/url-rules
{
    "path_pattern": "^/admin/.*",
    "rule_categories": ["sql_injection", "xss", "command_injection"],
    "cc_enabled": true,
    "cc_rate": 30,
    "cc_window": 60,
    "override_site_rule": true
}

# 更新URL规则
PUT /api/url-rules/{rule_id}
{
    "cc_rate": 50
}

# 删除URL规则
DELETE /api/url-rules/{rule_id}

# 查看站点URL规则
GET /api/sites/{site_id}/url-rules
```

**参数说明：**
- `path_pattern`: URL匹配模式（正则表达式）
- `rule_categories`: 启用的规则分类（为空则使用站点默认）
- `cc_enabled`: 是否启用CC防护
- `cc_rate`: CC防护速率阈值（请求/秒）
- `cc_window`: CC防护时间窗口（秒）
- `override_site_rule`: 是否覆盖站点级配置

**匹配优先级：**
1. 多个URL规则匹配时，使用创建时间最晚的规则
2. `override_site_rule=true` 时，完全覆盖站点级配置

---

### 5. 维护模式（一键关停）

快速关闭站点，显示维护页面。

**API接口：**
```bash
# 开启维护模式
POST /api/sites/{site_id}/maintenance
{
    "enabled": true,
    "message": "系统维护中，预计30分钟后恢复"
}

# 关闭维护模式
POST /api/sites/{site_id}/maintenance
{
    "enabled": false
}
```

**503维护页面：**
- HTTP 503 状态码
- 显示维护提示信息
- 美观的维护页面样式

---

### 6. 报告生成与导出

生成防护统计报告，支持多种格式导出。

**API接口：**
```bash
# 生成日报
POST /api/reports/generate
{
    "report_type": "daily",
    "site_id": 1,
    "date": "2024-01-15"
}

# 生成周报
POST /api/reports/generate
{
    "report_type": "weekly",
    "site_id": 1,
    "date": "2024-01-15"
}

# 生成月报
POST /api/reports/generate
{
    "report_type": "monthly",
    "site_id": 1,
    "year": 2024,
    "month": 1
}

# 生成汇总报告
POST /api/reports/generate
{
    "report_type": "summary",
    "start_date": "2024-01-01",
    "end_date": "2024-01-31",
    "site_ids": [1, 2, 3]
}

# 获取报告列表
GET /api/reports?report_type=daily&site_id=1

# 导出JSON格式
GET /api/reports/{report_id}/export/json

# 导出CSV格式
GET /api/reports/{report_id}/export/csv
```

**报告内容：**
- 总攻击数
- 攻击类型分布
- 严重程度分布
- 操作分布（拦截/放行）
- Top攻击IP
- 时间趋势图表数据

## 📝 注意事项

1. **GeoIP数据库**：当前使用内置IP段映射，生产环境建议使用 `geoip2` 库和官方数据库
2. **数据库迁移**：新增了数据表和字段，首次运行会自动创建
3. **缓存机制**：各模块实现了缓存机制，提高性能
4. **API权限**：所有API接口都需要登录权限
